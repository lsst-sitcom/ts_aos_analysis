# Folder Contents

This folder contains scripts useful for running processing at USDF.

## Folder Structure

- **bps_scripts/**
    - Contains scripts used to run batch processing at USDF.
    These scripts use pipeline files that have been added to the pipelines folder in `ts_wep`.
    For more information on how to run these at USDF see [LSST Developer Documentation](https://developer.lsst.io/usdf/batch.html).
